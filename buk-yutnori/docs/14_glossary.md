# 용어

- **결과 토큰(ResultToken)**: 한 번의 윷 던지기 결과를 안정적인 토큰 ID와 생성 원인과 함께 큐에 표현한 값
- **북 토큰**: 거리값이 아니라 강제 이동을 실행하는 특수 결과 토큰
- **북 장벽**: 북보다 뒤에 있는 결과를 북 처리 전에 사용할 수 없다는 규칙
- **위치 그룹**: 같은 칸에 있는 아군 말 집합. 업기 여부와 무관하게 북 선택 단위로 사용
- **업기 묶음**: 업기 허용 규칙에 의해 하나처럼 이동하는 말 집합
- **홈 체크포인트**: 출발점에 돌아왔으나 아직 완주하지 않은 상태
- **실제 직전 칸(actual_previous_space)**: 현재 이동 단위가 마지막으로 실제 통과하거나 북 이동 직전에 있던 칸. 백도의 다음 목적지이며 이동 후마다 갱신된다.
- **완주 거리**: 현재 위치에서 합법적인 전진 경로로 가상 완주 지점까지 도달하는 최소 이동 칸 수
- **스냅샷 경계 sequence**: 스냅샷에 원자적으로 포함된 마지막 서버 이벤트 sequence. 누락 이벤트는 이 값보다 큰 sequence부터 이어진다.
- **서버 권위형**: 최종 게임 상태를 서버만 판정하는 구조
- **확정 이벤트**: 서버 상태에 이미 반영되어 롤백하지 않는 이벤트
- **정본 명세**: 구현과 테스트가 따라야 하는 우선 문서
