# 제품 범위

## 제품 정의

로그인 사용자가 공개방을 만들거나 참여하여 두 팀으로 실시간 윷놀이를 진행하는 웹 게임이다. 게임 진행 중인 방은 관전할 수 있으며, 연결이 끊긴 플레이어는 CPU가 대신하고 경기 종료 전 재접속할 수 있다.

## v1 포함

- Google 로그인
- 로그인 후 방 목록 조회
- 공개방 생성 및 입장
- 방 비밀번호
- 최대 플레이어 2/4/6/8명
- A/B 팀 수동 선택
- 모든 플레이어 준비 완료
- 방장 시작
- 팀 내 무작위 고정 순서
- 선공 동전 던지기
- 2·3·4개 말 옵션
- 업기, 잡기 추가 던지기, 윷/모 추가 던지기
- 선택/강제 지름길
- 백도
- 북윷과 북 위치 무작위
- 이동 결과 순서 강제/자유
- 던지기 및 이동 제한 시간
- 재접속
- CPU 대체
- 실시간 관전
- 전체 채팅
- 프로필: 닉네임, 승, 패, 공개 여부
- 재대결
- 운영자 관리 기능

## v1 제외

- 랭킹
- 친구 목록
- 친구 초대
- 팀 전용 채팅
- 비속어 필터
- 개인 차단/음소거
- 사용자 신고
- 플레이어 합의 포기
- 서버 재시작 후 경기 복구

## 규모

- 프로토타입 동시 접속자 목표: 10~50명
- 방당 플레이어와 관전자 합계: 최대 20명
