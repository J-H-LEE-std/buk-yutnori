# 구현 계획

## Milestone 0 — 문서와 ADR

- 디렉터리 골격
- CI
- 최초 import, 원격 연결과 `main` 보호를 포함한 bootstrap
- GitHub Flow, PR 템플릿과 정책 검사
- 포맷터·린터
- ADR 템플릿
- 명세 검사
- SQLite 고정 버전·WAL·백업/복원 검증
- 실제 목표 부하와 장애 주입 기준선 측정

Milestone 0~1은 필수 외부 승인 수가 0이다. 자기 검토, Codex 자체 리뷰와 적용 가능한
모든 CI는 필수다.

## Milestone 1 — 규칙 코어와 보드

- 도메인 타입
- 방 설정
- `spec/board_graph.yaml` 로더와 무결성 검사
- 전체 경로 및 지름길 계산
- 확률 RNG
- 결과 큐
- 턴 상태 머신
- 업기·잡기·백도·북
- CPU 정책

## Milestone 2 — 웹 수직 프로토타입

- raylib WASM
- HTML 셸
- Google 로그인
- 30일 자체 세션
- WebSocket
- `(user_id, command_id)` 멱등 결과 재전송
- 한글 채팅
- 두 브라우저 동기화
- 새로고침 재접속

Milestone 2부터 고위험 변경은 사람, 별도 에이전트 세션 또는 외부 모델의 독립
리뷰 1회를 요구한다. 게임 규칙 의미 변경은 모든 Milestone에서 사용자 승인이
필수다.

## Milestone 3 — 방과 경기 서버

- 방 목록
- 방 생성/입장
- 팀 선택
- 준비
- 시작 확인
- 10초 시작 확인 취소 전이
- 보존 가능한 턴·일시 정지 타이머
- 경기 이벤트 DB 저장 후 상태 확정과 저장 장애 자동 정지
- CPU 대체
- 경기 종료/재대결

## Milestone 4 — 전체 보드 UI 통합

- 참고 좌표 기반 판 렌더링
- 지름길 선택 UI
- 말 겹침과 업기 표현
- 백도·북 애니메이션
- 모바일/데스크톱 반응형 배치

## Milestone 5 — 관전·채팅·프로필

- 관전자
- 전체 채팅
- 전적
- 공개 프로필
- 게임 로그

## Milestone 6 — 운영

- 관리자
- Docker
- HTTPS/WSS
- 모니터링
- 부하 테스트
- SQLite 확장 전환 조건 판정
- 브라우저 호환 테스트
