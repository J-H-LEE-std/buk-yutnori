# 채팅, 관전, 관리자

## 채팅

- 대기실 및 게임 내 전체 채팅
- 관전자 참여 가능
- 팀 전용 채팅 없음
- 메시지는 Unicode code point 기준 최대 200자
- 같은 사용자의 승인 메시지는 sliding 1초 구간에 최대 3개
- 프로토콜상 유효한 `SEND_CHAT` 시도는 rate limit이나 동일 메시지 거부 여부와
  관계없이 사용자별 발송 기록에 포함한다. sliding 5초 구간의 16번째 시도부터
  1분 채팅 차단
- 같은 사용자가 마지막 승인 메시지와 byte-for-byte 동일한 텍스트를 5초 미만에
  다시 보내면 거부하며 정확히 5초 뒤에는 허용
- 비속어 필터 없음
- 개인 음소거·차단·신고 없음
- 채팅은 경기 로그와 함께 저장
- 보존 기간은 미결정

Milestone 2 수직 프로토타입은 로그인한 연결을 고정 `prototype-room`에 자동
구독시키며 메모리에서만 전달한다. 정식 방 membership, 닉네임 표시, 영구 로그와
재접속 복구가 없는 운영 비대상 경계는
`adr/0008_in_memory_prototype_chat.md`를 따른다.

## 관전

- 로그인 사용자만 가능
- 진행 중 공개방을 방 목록에서 선택
- 비밀방은 비밀번호 필요
- 지연 없는 실시간 관전
- 관전자는 다음을 모두 볼 수 있음:
  - 윷 결과
  - 결과 큐
  - 선택 가능한 말
  - 전체 채팅
  - 연결 상태
  - 남은 시간
  - 북 목적지
- 팀 채팅이 없으므로 비공개 팀 정보 없음
- 게임 중 관전자→플레이어 전환 불가
- 게임 전/후 관전자→플레이어는 방장 승인 필요
- 게임 전/후 플레이어→관전자는 방장 승인 없이 가능
- 플레이어+관전자 최대 20명

## 관리자 기능

운영자는 최소한 다음 기능을 가진다.

- 방 목록 조회
- 진행 중 경기 조회
- 방/경기 강제 종료
- 사용자 접속 차단
- 채팅 제재
- 서버 공지

세부 UI와 권한 모델은 기술 설계에서 확정한다. 모든 관리자 조치는 감사 로그에 기록한다.
