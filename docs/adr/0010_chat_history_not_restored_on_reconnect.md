# ADR-0010: 재접속 시 이전 채팅 기록을 복구하지 않음

- 상태: 채택
- 결정일: 2026-08-19

## 맥락

Milestone 2 브라우저 수용 검사에서 새로고침 뒤 세션과 WebSocket 연결은 정상적으로
다시 만들어졌지만 기존 채팅 DOM 목록은 사라졌다. 기존 `game_snapshot` 초안은 최근
채팅을 복구 항목으로 포함했고 정확한 개수와 페이지 경계는 미결정 상태였다.

채팅은 게임 판정과 진행에 영향을 주지 않는 부가 기능이다. 채팅 목록 복구를 위해
game snapshot, event replay와 UI 상태에 별도 결합을 추가하면 authoritative 경기 상태
재동기화의 범위와 실패 조건이 불필요하게 커진다.

## 결정

- 새로고침·재접속 뒤 이전 채팅 기록을 화면에 복구하지 않는다.
- 새 연결은 연결 이후 서버에서 확정된 `CHAT_MESSAGE`만 표시한다.
- 이전 채팅 목록이 비어 있어도 reconnect 실패나 `RESYNC_REQUIRED` 사유가 아니다.
- `game_snapshot`은 채팅 기록을 포함하지 않는다.
- 채팅의 서버 저장, 운영 로그와 보존 기간은 별도 정책이며 화면 replay 여부와
  분리한다. 저장된 채팅이 존재하더라도 reconnect snapshot으로 반환할 의무는 없다.
- 이 결정은 게임 event snapshot과 누락 event replay 요구를 변경하지 않는다.

## 결과

- 브라우저 새로고침 뒤 채팅 목록이 비어 있는 동작은 정상이다.
- 재동기화 성공 여부는 방·경기·턴·결과 큐·말 위치와 권한 상태만으로 판정한다.
- 최근 채팅 snapshot 개수와 페이지 경계 미결정 항목은 제거한다.
- 사용자는 채팅이 부가 기능임을 근거로 이 제한을 수용했으며 이번 변경에서 별도
  복구 구현을 요구하지 않았다.
