# 게임 규칙 정본

## 팀과 말

- 각 팀은 방 설정에 따라 2, 3, 4개의 말을 공동 소유한다.
- 현재 차례인 플레이어만 조작할 수 있다.
- 현재 플레이어는 자기 팀의 모든 말을 조작할 수 있다.
- 팀 내 플레이어 순서는 게임 시작 시 무작위로 정하고 경기 종료까지 고정한다.
- 양 팀은 `A1 → B1 → A2 → B2 ...` 순으로 교대한다.
- 추가 행동은 해당 행동을 얻은 현재 플레이어가 계속 수행한다.
- 재대결 시 팀 내 순서와 선공 팀을 모두 다시 추첨한다.

## 출발과 완주

- 출발점은 첫 이동 칸으로 세지 않는다.
- 도가 나오면 출발점에서 한 칸 앞에 놓는다.
- 백도로 새 말을 출발시킬 수 없다.
- 남은 칸 수보다 큰 양의 이동값도 완주할 수 있다.
- 말이 한 바퀴를 돌아 출발점 체크포인트에 정확히 멈춘 것만으로는 완주하지 않는다.
- 출발점 체크포인트 상태의 말이 다음 유효한 전진 이동을 수행하면 완주한다.
- 첫 칸의 말이 백도로 출발점으로 돌아가도 체크포인트를 찍은 것으로 취급한다. 이 규칙은 의도된 특수 규칙이다.
- 완주한 말은 다시 판에 돌아오지 않으며 백도·북 후보에서 제외한다.
- 업힌 말은 함께 완주한다.

## 업기

- 업기 허용 시 아군 말이 같은 칸에 도착하면 자동으로 업힌다.
- 업힌 묶음은 하나의 말처럼 이동한다.
- 업힌 묶음은 임의 분리할 수 없다.
- 묶음이 잡히면 모든 말이 출발 대기로 돌아가고 업힘이 해제된다.
- 업기 불가 시 같은 칸에 아군 말이 독립적으로 공존할 수 있다.

## 잡기

- 상대 팀 말이 있는 칸에 도착하면 해당 칸의 상대 말 전체를 잡는다.
- 업기된 묶음과 업기 불가 상태의 독립 말 모두 칸 단위로 전부 잡힌다.
- 잡힌 말은 출발 대기 상태로 돌아간다.
- 백도 또는 북 이동으로 잡아도 일반 잡기로 처리한다.

### 잡기 추가 던지기 옵션

- `always`: 모든 결과에 의한 잡기에 추가 던지기
- `do_to_geol_plus_special`: 도·개·걸·백도·북에 의한 잡기에 추가 던지기
- `none`: 어떤 잡기에도 추가 던지기 없음

잡기 추가 던지기가 발생하면 이동 처리를 중단하고 즉시 던진 뒤 결과를 큐 뒤에 추가한다.

## 윷과 모

- 윷/모 추가 던지기 옵션이 켜져 있으면 윷 또는 모 결과 직후 즉시 추가로 던진다.
- 연속 윷/모는 추가 던지기가 끝날 때까지 반복한다.
- 결과 토큰은 발생 순서대로 큐에 들어간다.

## 사용할 수 없는 결과

- 사용할 수 없는 일반 결과는 해당 토큰만 소멸한다.
- 이후 큐에 남은 결과를 계속 처리한다.
- 큐가 비거나 남은 결과가 전부 처리되면 턴을 종료한다.

## 백도

- 판에 움직일 말이 없을 때 백도만 있으면 사용할 수 없어 소멸하고, 남은 큐가 없으면 턴을 종료한다.
- 백도는 새 말을 판에 올릴 수 없다.
- 백도는 현재 말이 진입했던 경로를 우선하여 한 칸 역행한다.
- 갈림길의 역행 경로가 모호하고 진입 경로로 해결되지 않으면 지름길이 아닌 경로를 사용한다.
- 백도만으로 중앙 `방`에 새로 진입할 수 없도록 그래프를 구성한다.
- 백도로 잡으면 일반 잡기 및 방 옵션에 따른 추가 던지기를 적용한다.

### 백도 경로 상태

- 판 위 또는 홈 체크포인트 상태의 각 말은 nullable `actual_previous_space`를 가진다.
- 일반 이동 후 `actual_previous_space`는 도착 칸 바로 전에 실제로 통과한 칸으로 갱신한다.
- 백도는 현재 칸에서 `actual_previous_space`로 이동한 뒤, 백도 이동 전의 현재 칸을 새 `actual_previous_space`로 설정한다.
- 따라서 백도를 연속으로 사용하면 매 이동마다 직전의 두 칸 사이를 역행 기준에 따라 오갈 수 있다.
- 합류점에서 업기가 발생해 말들의 경로 상태가 충돌하면, 마지막으로 이동하여 업기를 발생시킨 말 또는 묶음의 `actual_previous_space`를 새 묶음 전체가 승계한다.
- 업기 불가 상태에서 같은 칸에 공존하는 말은 각자의 `actual_previous_space`를 유지한다.
- 북이 같은 칸의 여러 말을 함께 이동시키면 이동한 모든 말의 `actual_previous_space`를 북 이동 직전의 공통 출발 칸으로 설정한다.
- 북 이동 후 백도는 북 이동 직전의 출발 칸으로 이동한다.
- 잡혀 출발 대기로 돌아간 말과 완주한 말은 경로 상태를 제거한다. 출발 대기 말에는 경로 상태가 없다.
- 홈 체크포인트에서 백도를 사용하면 홈 체크포인트에 들어오기 직전의 `actual_previous_space`로 돌아간다.
- 첫 칸 `도`에서 백도로 참먹이에 도착한 말의 `actual_previous_space`는 `도`다. 그 상태에서 다시 백도를 사용하면 `도`로 돌아간다.

## 북

- 북은 일반 이동 거리값이 아닌 특수 결과 토큰이다.
- 북도 결과 큐에 삽입되며, 앞선 결과보다 먼저 처리할 수 없다.
- 북 앞의 결과가 처리된 뒤 북이 처리 가능한 선두가 되면 즉시 강제 이동을 실행한다.
- 북 처리 후 북 토큰을 큐에서 제거하고 남은 결과를 계속 처리한다.
- 예: `[윷, 북]`은 윷 이동 후 북 강제 이동 순서다.
- 북 앞의 결과로 처음 말을 판에 올릴 수 있다.

### 북 대상

- 판 위에 있으며 완주하지 않은 아군 말 또는 위치 그룹만 후보다.
- 출발 대기와 완주 말은 제외한다.
- 완주까지 남은 칸 수가 가장 적은 위치 그룹을 선택한다.
- 동률이면 서버 난수를 사용한다.
- 동률 가중치는 해당 위치 그룹의 현재 말 개수다.
- 업기 불가 상태라도 같은 칸의 아군 말은 북 선택에서 하나의 위치 그룹으로 보며, 선택 시 모두 이동한다.
- 선택된 그룹이 이미 북 목적지에 있으면 이동 없이 북을 소모한다.
- 후보가 없으면 북은 무효화되고 즉시 턴을 종료한다. 정상 생성 흐름에서는 북 뒤에 처리할 토큰이 없어야 한다.

### 완주까지 남은 칸 수

- 현재 말 또는 위치 그룹의 현재 위치에서 완주까지 도달할 수 있는 합법적인 전진 경로 중 최소 이동 칸 수를 사용한다.
- 계산 모델에서는 `참먹이`의 홈 체크포인트 뒤에 1칸 거리의 가상 완주 지점을 둔다. 판 위 말의 거리는 현재 위치에서 합법적인 전진 경로로 참먹이에 도달하는 거리와 마지막 완주 1칸을 합한 값이다.
- `shortcut_policy = selectable`이면 선택 가능한 합법적 전진 경로 중 최단거리를 사용한다.
- `shortcut_policy = forced`이면 각 분기에서 강제된 경로만 사용한다.
- 이미 지름길 내부에 진입한 말은 현재 위치에서 이어지는 전진 경로만 사용한다.
- 홈 체크포인트 상태의 거리는 1이다.
- 출발 대기와 완주 말은 이 거리 비교 대상에서 제외한다.
- 북 대상 선택과 CPU의 `완주에 가장 가까운 말` 판단은 같은 거리 계산 함수를 사용한다.

### 북 도착 처리

- 업기 허용 상태에서 아군 말이 있으면 자동으로 업는다.
- 업기 불가 상태에서는 같은 칸에 독립적으로 둔다.
- 상대 말이 있으면 전부 잡는다.
- 잡기 추가 던지기 옵션을 적용한다.
- 북 목적지는 교차점이나 지름길 분기점이 아니다.

### 북 목적지

- 무작위 설정 꺼짐: 찌도
- 무작위 설정 켜짐: 게임 시작 시 아래 중 하나를 서버가 선택하고 즉시 공개
  - 뒷도, 뒷개, 뒷걸, 뒷윷
  - 찌도, 찌개, 찌걸, 찌윷
  - 속윷, 속모

## 승리

팀의 모든 말이 완주하면 즉시 승리한다.
