# Q&A 이후 추가 확정 사항

## 확률

백도·북 표식은 서로 다른 윷가락에 있으며, 특정 표식 윷가락 하나만 뒤집힌 단독 도 조합이 각각 특수 결과를 대체한다.

명목 확률:

- 특수 없음: 도 14.38
- 백도만: 도 10.79, 백도 3.59
- 북만: 도 10.79, 북 3.59
- 둘 다: 도 7.20, 백도 3.59, 북 3.59
- 개 33.89, 걸 35.49, 윷 13.94, 모 2.29는 동일

반올림 합계가 99.99가 될 수 있으므로 구현은 제공 가중치를 합계로 정규화한다.

## 큐

- 윷/모가 나오면 즉시 추가 던지기
- 잡으면 즉시 추가 던지기
- 사용할 수 없는 결과는 해당 결과만 소멸
- 북은 큐에 삽입
- 북 앞의 일반 결과를 먼저 처리
- 북이 처리 순서가 되면 강제 이동
- `[윷, 북]`은 윷 이동 후 북
- 북 후보 없음은 판 위 후보가 없다는 뜻이며, 대기 말 보충 후보도 없을 때만 북 무효 및 즉시 턴 종료

### Issue #163 규칙 정합성 갱신

- 북은 결과 큐의 순서 장벽으로 유지한다. 북 뒤에 이동 스택이 남아 있어도 북을 먼저
  강제 처리하고 북 토큰 제거 후 같은 턴의 남은 큐를 계속 처리한다.
- 북 최소 완주 거리의 동률 위치 그룹은 모두 북 위치로 이동한다. 동률 무작위 선택과
  묶음 수 가중치는 폐기한다.
- 판 위에 완주하지 않은 아군 후보가 없으면 완주하지 않은 대기 말 중 하나를 서버
  난수로 선택해 북 위치로 보낸다. 백도 후보 부재는 기존대로 해당 토큰만 소멸시킨다.
- 강제 지름길이 뒷모에서 시작해 방을 통과하면 방수기 방향으로 계속 이동한다.

## 중앙

- 모개 → 방
- 뒷모개 → 방
- 방 → 속윷
- 방 → 방수기(지름길)
- 백도로 방 신규 진입 불가

## 추가 운영

- 일시 정지 1회, 1~30분, 타이머·CPU 정지
- 방장 연결 끊김 시 자동 재개
- 양 팀 전원 이탈 30초 후 경기 무효 및 방 폐쇄
- 게임 종료 후 플레이어 0명이면 방 즉시 폐쇄
- 게임 종료 방장 재선정 후보는 플레이어만
- 재대결마다 선공 재추첨
- 로그인 유지 30일 우선

## 전체 윷판

- 전체 판은 제공된 기준 그림을 따른다.
- 참먹이는 출발점이다.
- 기계 정본은 `spec/board_graph.yaml`이다.
- 전체 노드와 논리 연결은 확정되었다.

## 북 목적지 후보 갱신

무작위 북 목적지는 다음 10개로 확정한다.

- 뒷도, 뒷개, 뒷걸, 뒷윷
- 찌도, 찌개, 찌걸, 찌윷
- 속윷, 속모

모도, 뒷모도, 뒷모개는 북 무작위 목적지 후보가 아니다.
