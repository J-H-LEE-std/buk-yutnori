# 윷판 그래프와 이동

## 기준 판

본 프로젝트의 논리 윷판은 `assets/board_reference/yut_board_reference.png`의 구조를 따른다.

- 출발점 및 출구: `참먹이`
- 기계 판독 가능한 정본: `spec/board_graph.yaml`
- 문서와 그림이 YAML과 충돌하면 구현 전 문제를 보고하며, 코드에서는 임의로 보정하지 않는다.

## 외곽 정방향

참먹이에서 출발하여 다음 순서로 진행한다.

```text
참먹이
→ 도 → 개 → 걸 → 윷 → 모
→ 뒷도 → 뒷개 → 뒷걸 → 뒷윷 → 뒷모
→ 찌도 → 찌개 → 찌걸 → 찌윷 → 찌모
→ 날도 → 날개 → 날걸 → 날윷
→ 참먹이
```

## 지름길

### 모 분기

- 일반: `모 → 뒷도`
- 지름길: `모 → 모도 → 모개 → 방`

### 뒷모 분기

- 일반: `뒷모 → 찌도`
- 지름길: `뒷모 → 뒷모도 → 뒷모개 → 방`

### 중앙 방 분기

- 일반: `방 → 속윷 → 속모 → 찌모`
- 지름길: `방 → 방수기 → 안찌 → 참먹이`

분기점에 정확히 도착한 말만 다음 전진 이동에서 분기 정책을 적용한다.

- `selectable`: 플레이어가 일반/지름길 선택
- `forced`: 지름길 방향 강제

## 중앙 `방`

- 모개와 뒷모개에서 진입하는 경로는 같은 논리 칸 `방`으로 합류한다.
- 어느 경로에서 들어왔든 `방`에서 업기와 잡기가 가능하다.
- `방`에서 다음 전진은 속윷 또는 방수기 방향이다.
- 백도는 실제 직전 이동 경로를 따른다.
- 속윷·방수기 등 인접 칸에서 백도로 `방`에 돌아오는 것은, 실제 직전 칸이 `방`이었던 경우에만 허용한다.
- 백도로 인접 칸에서 `방`에 새로 진입할 수는 없다.

## 데이터 모델

윷판은 방향성과 분기를 가진 그래프다. 정적 보드 구조와 동적 경기 상태를 분리한다.

### 정적 노드

- 고유 `space_id`
- 표시 이름
- 정상 전진 연결
- 지름길 연결
- 분기·중앙·출발·북 후보 태그
- 렌더링 좌표

### 동적 말 상태

- 말 ID
- 팀 ID
- 출발 대기 / 판 위 / 홈 체크포인트 / 완주
- 현재 칸
- 실제 직전 칸
- 업기 묶음 또는 위치 그룹

백도 판정을 위해 nullable `actual_previous_space`를 보관한다. 전체 이동 이력 스택은 사용하지 않는다.

### 최소 경로 상태 모델

- 일반 전진 이동 후 `actual_previous_space`는 도착 직전에 실제로 통과한 칸이다.
- 백도는 `actual_previous_space`로 이동하고, 이동 전 현재 칸을 새 `actual_previous_space`로 설정한다.
- 합류점에서 업기가 발생하면 마지막으로 도착하여 업기를 발생시킨 말 또는 묶음의 경로 상태를 새 묶음 전체가 승계한다.
- 업기 불가 상태의 말들은 같은 칸에 있더라도 각자의 경로 상태를 유지한다.
- 북으로 이동한 모든 말은 북 이동 직전의 공통 칸을 `actual_previous_space`로 가진다. 다음 백도는 그 칸으로 돌아간다.
- 출발 대기 또는 완주 상태에서는 `actual_previous_space`가 `null`이다.
- 잡혀 출발 대기로 돌아가거나 완주하면 `actual_previous_space`를 `null`로 초기화한다.
- 홈 체크포인트에서도 진입 직전 칸을 유지한다. `도 → 참먹이` 백도 후에는 `actual_previous_space = do`이므로 다음 백도는 도로 돌아간다.

현재 칸과 직전 칸의 쌍만으로 일반 이동, 연속 백도, 북 복귀, 홈 체크포인트 복귀 및 업기 승계 규칙을 모두 표현할 수 있으므로 전체 경로 스택은 필요하지 않다.

## 완주 거리

`remaining_forward_distance`는 현재 위치에서 완주까지 도달하는 합법적인 전진 경로 중 최소 이동 칸 수다.

- 계산용 그래프에서 홈 체크포인트 `참먹이` 뒤에 거리 1의 가상 완주 지점을 둔다.
- 선택 지름길에서는 가능한 모든 합법적 전진 경로 중 최소값을 사용한다.
- 강제 지름길에서는 강제 간선만 사용한다.
- 이미 내부 경로에 진입한 말은 현재 노드에서 도달 가능한 전진 간선만 사용한다.
- 홈 체크포인트의 거리는 1이다.
- 출발 대기와 완주 상태에는 비교 가능한 완주 거리를 부여하지 않는다.
- 북 대상 선택과 CPU 정책은 이 동일한 함수를 호출해야 한다.

## 출발과 홈 체크포인트

- 참먹이는 출발점이다.
- 새 말의 도 이동은 참먹이 다음 칸인 `도`에 놓는다.
- 한 바퀴를 돌아 참먹이에 정확히 멈춘 말은 홈 체크포인트 상태다.
- 홈 체크포인트 상태에서 다음 유효한 전진 결과를 사용하면 완주한다.
- 첫 칸 `도`에서 백도로 참먹이에 돌아온 경우에도 홈 체크포인트가 된다.

## 북 목적지

고정 목적지는 `찌도`다.

무작위 후보:

- 뒷도, 뒷개, 뒷걸, 뒷윷
- 찌도, 찌개, 찌걸, 찌윷
- 속윷, 속모

중앙 `방` 및 전진 경로를 선택해야 하는 분기점은 북 목적지가 아니다.

## 렌더링 좌표

`spec/board_graph.yaml`에 참고 그림을 바탕으로 정규화된 근사 좌표를 제공한다. 이는 초기 UI 배치용이며, 논리적 연결보다 권위가 낮다.
